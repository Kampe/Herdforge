## Summary of Fixes
1. **Durable Handoff Parser Hardening**:
   - `ParseStructuredHandoffReport` strictly validates required structured fields: `TaskRef`, `AgentName`, `CandidateSHA` (valid 40-hex SHA), and `Status`.
   - Rejects non-ready/incomplete verdicts (`BLOCKED`, `FAIL`, `WORKING`, `NOT READY`, etc.).
   - Rejects conflicting duplicate fields (e.g. `Status: READY` vs `Status: BLOCKED`, duplicate conflicting tasks or agents).
   - Correctly ignores quoted prose lines (markdown `>`) and markdown code blocks (``` ... ```) so prose or code snippets cannot be mistaken for top-level structured headers.

2. **Launch Exact Authority & Provenance**:
   - `findLaunchReceipt` and `EvaluateSourceRetirement` strictly bind repository, authorized source role (`worker`, `forge-smith`, `recovery`, `mender`), task, agent, candidate SHA, branch, worktree, session, tab ID, and pane ID.
   - Refuses absent, ambiguous, malformed, or foreign receipt matches instead of picking latest partial match.
   - `observeHandoff` strictly uses parsed values from report artifact without backfilling unparsed fields from manifest.

3. **Close-Time Race Check**:
   - `CloseSettledSourceTab` inspects live pane processes immediately before issuing fenced close; aborts and refuses close if any non-idle foreground or descendant process (e.g. `make`, `go test`, active shell commands) is detected.

4. **Mixed Batch / Fail-Closed Isolation**:
   - `RetireSourceLanesContext` isolates per-lane evaluation and mutations: eligible own settled lanes retire cleanly while invalid, blocked, or failed lanes fail-closed with aggregate error summaries without aborting the entire batch.
   - In `cmd/herd/drainadapt.go`, `sweepSourceRetirement` gracefully handles mixed batches where some lanes are blocked without failing the coordinator drain cycle.

5. **WSL CI Cleanup Fixture Compatibility**:
   - `runSourceRetirementCleanup` in `cmd/herd/source_cleanup_native.go` gracefully handles environments where `.herd/herd.yaml` is absent without failing.
