## Findings

[P1] Wire shell-owner discovery to paths this repository can actually track — cmd/herd/testsfor.go:348

`candidateShellOwners` emits owners only when `path.Dir(repoPath) == "tests"` and the name ends in `.zsh`, or `path.Dir(repoPath) == "bin"` and the blob is mode `100755` with a zsh shebang. It also hardcodes the unbound-vars gate as `bin/check-unbound-vars` (line 337).

On this candidate tree those directories do not exist as tracked content. `.gitignore` lists `bin/` as compiled output (`./scripts/build-herd.sh` writes `bin/herd`). `git ls-tree -r HEAD` has no `bin/` and no `tests/` blobs. The executable zsh that *is* tracked lives under `scripts/` (`scripts/security-gate.zsh` 100755, sibling `scripts/security-gate_test.zsh`, `scripts/check-go-dependencies.zsh`), plus nested `scripts/host/*.sh`. Because discovery reads `git ls-tree` of the candidate, it will never see gitignored `bin/` scripts either.

Consequence: production `herd tests-for` on Herdforge never selects a shell owner and never takes `suppressGoProfile`. A shell-only diff of `scripts/security-gate.zsh` still gets `go vet/build/test ./...` — the exact failure FAC-645 describes. FAC-113 requires this CLI to work on this repo. The green CLI tests only construct a synthetic `bin/` + `tests/ship.zsh` fixture that this tree cannot produce as a real revision pair.

Fix: discover executable zsh (and sibling tests) from the tracked layout this factory uses (`scripts/`, `*_test.zsh` next to the script, and only then any real `bin/` / `tests/` convention). Keep Plan as the merge authority. Add a shipped-path CLI test whose fixture matches a path `git ls-tree HEAD` can actually contain.

[P2] Do not treat a `--selftest` substring as a declared capability — cmd/herd/testsfor.go:416

`declaresSelftest` is `strings.Contains(body, "--selftest")`. Any comment, usage string, or rejection message that mentions the flag adds `zsh <path> --selftest` to the plan. If that invocation exits non-zero, verification fails for a script that never implemented the capability. The card forbids inventing semantic test edges; a literal scan of the whole blob is still a fabricated edge. Restrict the match to an explicit handler (for example a `case` arm or `--selftest)` on its own token line) or require a dedicated declaration comment.
