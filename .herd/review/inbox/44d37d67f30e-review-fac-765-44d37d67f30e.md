   (`journalDir = migrateJournalDir(journalDir)`, pkg/deps/migrate.go:611)
   and persists it via `rememberMigrateJournalRoot` (migrate_phase.go:80)
   *before* the journal file is written, into a roots file under the
   canonical default journal dir — so the write happens regardless of
   which `--journal` root was used.
2. `knownMigrateJournalRoots("")` (migrate_phase.go:104) unions the
   canonical dir, the literal `DefaultMigrateJournalDir` constant (so an
   env override doesn't hide the default), and every remembered root read
   back from that roots file — then `PendingRollbackJournals` scans all of
   them. An explicit non-empty `journalDir` argument still scans only that
   one dir, unchanged, which is what the new proof test exploits to show
   the old default-dir-only behavior specifically.
3. Both production call sites (`gate.go:97`, `main.go:3040`) call
   `RefusePendingRollback("")`, so both now inherit the full remembered-root
   scan. No other call sites for `RefusePendingRollback`/`ValidateLaunch`
   exist outside tests/fixtures.
